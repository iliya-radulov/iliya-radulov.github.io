4. Wake-on-LAN client

Configured: 30 August 2026

This machine can wake the home server (192.168.2.42) from cold poweroff via a magic packet.

# Package installed
sudo apt install wakeonlan

# Alias added to ~/.bashrc
alias wakeserver='wakeonlan 2c:56:dc:74:c4:ff'

Usage:

wakeserver
# Server is reachable via SSH ~60-90 seconds later
ssh r@192.168.2.42

Tested and confirmed: cold poweroff → magic packet → SSH connected ✅
