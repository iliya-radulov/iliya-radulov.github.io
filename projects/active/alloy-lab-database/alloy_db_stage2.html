Stage 2 transforms the lab‑book foundation into a validated research platform. Every instrument pipeline is built on real data, not synthetic tests. The schema is designed for machine learning — and the infrastructure is now ready for Stage 3.

From scattered spreadsheets to a single source of truth

The project started with a messy desktop folder, years of Origin projects, and a growing set of manual spreadsheets. Stage 1 built the data‑capture layer — composition calculator, literature cross‑checking, and basic file import. Stage 2 adds the analytical layer: real, validated characterisation pipelines for every instrument in the lab, with results stored in a structured schema designed for machine learning.

XRD

Neighbour‑aware peak fitting

NIST LaB6 validation, Kα2 stripping, R² quality, Scherrer crystallite size, d‑spacing. 170 peaks, mean R² ≈ 0.938.

VSM

Multi‑segment hysteresis

Hc, Mr, BHmax, temperature coefficients α/β, entropy change ΔSm. Handles PPMS/MPMS3/ACMS, mass from filename.

SEM

Unified metadata parser

Zeiss, JEOL, Tescan (16‑bit). Adaptive thresholding, phase fraction with operator judgment. 690 images imported.

What was planned vs. what was built

The original design sketch included a full Docker Compose stack with MinIO, Redis, Jupyter, and a file‑watcher service. Real use showed that a leaner system — Postgres, a Python API layer, and a proper desktop interface — covered everything actually needed, without the operational overhead of running five services to enter one sample.

Knowing what to cut turned out to matter more than the original breadth of the plan.

What this enables for Stage 3

The database now contains a complete, validated feature set ready for ML:

  • compositions → element fractions (wt% + at%), all samples
  • xrd_features → n_peaks, mean R², crystallite size, d‑spacing
  • vsm_mh_details → Hc, Mr, BHmax per segment
  • vsm_temperature_coeff → α(Hc), β(Mr) — temperature stability
  • properties → SEM phase fraction, pixel calibration

Proposed ML workflow: feature matrix (compositions + structural features) → Gaussian Process or Neural Network regression → property prediction + optimisation suggestions → new composition recommendations → back into calculator → new samples.
